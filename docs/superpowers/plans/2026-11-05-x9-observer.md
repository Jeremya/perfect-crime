# X9 Observer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the player watch the round before drawing, walk the plan to the tick it fails, and read a cell's ticks while drawing.

**Architecture:** All logic lives in `src/game/observe.ts`, pure and Phaser-free, because CI runs no e2e. Observer is its own mode beside X3: a new `yapObserver` field and phase `observer`. The spike merged both modes; here the X3 code path does not change. The world always comes from `YapGhostPreview` and `yapPreviewStates`, so through `resolveTick`.

**Tech Stack:** Phaser 4, strict TypeScript, Vitest, Playwright.

**Spec:** `tasks/X9.md`. Reference only, never merged: branch `spike-observer`, commits `8c3f822`, `2ae1bb3`, `0d3a475`.

## Global Constraints

- Yap prefix on every type and function; all displayed text in the FR/EN dictionaries.
- `src/core/` does not change. No rule is computed in `observe.ts`.
- `?flag=observer:0/1`, default on (decided 2026-11-05). `?flag=night:1`, default off.
- No new dependency. No analytics event outside `track()`, no personal data.
- UI follows `docs/UI-DESIGN.md`: no text on the grid, 44 px minimum tap target, works at 360 × 640 in French.
- Full check before each push: `npm run typecheck && npm run lint && npm run test && npm run validate && npm run build`, then `npx playwright test tests/e2e`.

## Review Focus

1. A resize or a consent note during an observation keeps the frame, runs one timer, and leaves no second chrome.
2. A fatal marker on the plan survives an observation: Close brings it back.
3. Using the last hint relayouts the row under the finger: the release must not start Observer.
4. With `?flag=observer:0`, the row is exactly the one of `main`.
5. Under reduced motion, Observer opens paused and Play still works.
