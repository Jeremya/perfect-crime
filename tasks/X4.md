## Task

While drawing (not finished), dragging the finger **back along the last drawn
segments** erases them **one by one** — the path shrinks from the end, like
pulling the bird back in the slingshot (docs/design/experience.md §3.2).

Concretely, in `YapPathInput.yapPointerMove`, while the stroke is drawing: if
the pointer is **behind the last cell** of the path (projection `t < 1` on the
last segment) and within `YAP_UNDO_MAX_DISTANCE` (half a cell) of that segment,
pop the last cell — and repeat against the new last segment, so a fast backward
swipe pops one segment per crossed midpoint. This works **even in the border
strips**, where `yapCellAtPoint` resolves no cell (previously a no-op). The
start cell S is never popped (`yapCells.length > 1` guard). Pushing forward
again redraws the erased segments (the existing extend path re-adds them).

Kept unchanged: a simple tap stays a tap (pause on a path cell, nothing on the
last cell); auto-finish at the exit; no undo once finished; pause taps on a
completed route (fix #52). After an undo, `yapCanPlay` / `yapPlan` /
`yapSteps` / `yapPauseCounts` update naturally (the popped cell takes its pause
with it).
