## Definition of "medium" (target band, pinned by tests)
- `par` between **16 and 24** (tutorial t4 = 14, daily d3 = 22, d7 = 30)
- **2–3 guards**, **0–1 camera**, **0 lasers**, `maxPauses` 2–3
- standard map: 8 columns × 12 rows, one S, one E, one L
- patrol periods must divide 24 (enforced by `npm run validate`)

## Task
Design 10 medium heists in `levels/medium/`, one per mechanic moment, in
increasing pressure (teach → practice → test across the set):
m1 pingpong reading · m2 mandatory pause · m3 camera timing · m4 loop route ·
m5 two guards crossing · m6 narrow corridor under a sweep · m7 pause + camera ·
m8 three guards, staggered phases · m9 long route, tight par · m10 mixed
medium "signature-lite" (non-empty `moment`, still type `normal`).

Each `.lvl` follows the existing format (see levels/daily/d3.lvl): header
comment, `name`, `type: normal`, `moment`, `maxPauses`, `par`, ASCII `map`,
`guards` / `cameras`.

## Acceptance criteria

- Full local check green: `npm run typecheck && npm run lint && npm run test && npm run validate && npm run build`.
- The 10 levels appear in the /dev/viewer catalog (levels.json id `medium/mN`).
